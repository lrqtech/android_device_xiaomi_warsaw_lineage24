Warsaw official-device-tree review — updated 2026-10-27 (Asia/Shanghai)

Official requirements:
https://github.com/LineageOS/charter/blob/main/device-support-requirements.md
https://github.com/LineageOS/lineage_wiki/blob/main/pages/submitting_device.md

Scope: source editing and host validation only. No Android/kernel build,
APK/image/OTA packaging, flashing or phone access. This tree remains unofficial.

Completed device-tree cleanup:
- Global permissive normal/recovery boot overrides removed; default enforcing
  remains. Upstream userdebug su/backuptool and recovery-domain debug exceptions
  are unchanged. User policy has no permissive domains. Neverallow checks remain.
- Unused OEM GKI fallback and its three inputs removed. Paired source GKI,
  required firmware, DTB/DTBO and OEM modules retained.
- Optional SenseTime portrait restoration, its four inputs, six graph nodes and
  both support masks were removed/disabled in the previous cleanup.
- Vega SDK, Mi FD node, ECD engine/snapshot plugin/preprocessor, automatic face
  ROI codec filter and three Vega models removed in the October 27 follow-up.
  Six selector entries now use the original Qti FD node with matching descriptor
  and callback ABI. Optional facial attributes and closed-eye selection are off.
  The anchor bypass is unconditional even when old persistent properties differ.
  Three snapshot graphs bypass four ECD nodes, both codec filter lists are updated
  and the optional SenseTime Chat allowlist entry is removed.
- Eight unselected inputs from the earlier cleanup remain deleted. Existing
  repaired face-unlock/source service implementations and Xpan APK are preserved.
- Prepared extraction has 5,559 inputs and 2,265 modules. Exact-hash native
  preparation and a thirteen-path retirement guard prevent silent SDK reinsertion.
- Forty obsolete OEM service definitions, their RC/shell callers and nine
  dedicated payloads are removed. Legacy thermal-stop and modem chmod-777
  property actions are removed. Obsolete policy labels and grants are retired.
- Inline compatibility SHA1 pins are verified alongside complete SHA256 pins;
  invalid and duplicate pin entries are rejected. Retired init files, service
  definitions, callers and unsafe property triggers are rejected on import.
- Platform companion patches, source mirrors and previous repairs stay intact.

Validation boundaries:
- Same node descriptor/callback shape, unchanged ELF ABI, empty-data guards and
  graph reachability reduce integration risk; they are not hardware acceptance.
- The retired feature removal intentionally drops optional attributes/emotions,
  closed-eye best-frame selection, related snapshot processing, face ROI encoding
  and portrait restoration. Basic Qti FD and ordinary camera/codec paths remain.
- No missing direct ELF dependency may be introduced. Payload, APK/JAR code,
  metadata and configuration scans are used to check retired SDK references.
- Whole-device SELinux remains enforcing by default. No new permissive domain,
  broad policy allowance or dependency-check bypass is added for this cleanup.

Remaining official-support gaps:
1. Megvii-marked log strings in com.qualcomm.mcx.linearmapper.so,
   libcamxoemsatwrapper.so and com.xiaomi.node.alpha_blending.so still require
   ownership/embedded-code review. A log marker is not proof of whole-library
   ownership. This is separate from the removed Vega/SenseTime SDK.
2. Installed LineageOS/OTA extraction and reproducible fixups are not implemented
   and validated; the prepared importer is not a demonstrated extraction round trip.
3. 538 OEM kernel modules remain prebuilt. Source coverage and rebuilding all
   feasible modules remain open; the pinned source-built GKI is paired separately.
4. Enforcing cold boot/recovery, upgrades, camera/codec operation and full hardware
   acceptance are pending. Earlier crop/AWB, IR appliance response and shared
   camera terminal-error lifetime issues have not been proven completely repaired.

October 24 build/image results do not cover these later source changes. Passing
host checks does not establish official support or guarantee device operation.
